# StudyTrack Lab 2 — Original Screenshot Evidence

These screenshots were provided by the student in the ChatGPT conversation while completing StudyTrack Lab 2. The **PNG file contents are copied unchanged** into this archive; filenames are descriptive for navigation.

## Usage

Extract this ZIP into the root of your Android Studio `StudyTrack` repository. The images will appear under `docs/evidence/`. Review the screenshots, keep the ones you want to submit, and commit them on the `feature/lab2-cloud-crud-security` branch.

The accompanying `EVIDENCE_INDEX.csv` maps each descriptive filename to the original uploaded filename and documents what is visibly supported.

## Evidence boundaries

- The screenshot of an empty task list does not, on its own, prove authentication as a second user. Test user isolation separately.
- The R8 screenshot verifies **local emulator tests**, not a separate confirmation that published rules match the committed rules.
- These screenshots do not establish that PR #7 has received a review or been merged, that the `lab2` tag exists, or that the assignment has been submitted.
- Do not present any screenshot as evidence of a test it does not show.

No screenshots were generated, retouched, or reconstructed for this archive.
